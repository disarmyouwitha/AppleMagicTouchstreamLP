# Read-only motion capture tools

These tools capture the selected Mac trackpads' active pointer and scroll profiles
for the Windows experiment, and generate golden vectors from the Mac production
models. They do not run the app or produce live input.

See [the Windows motion profile notes](../../../../windows_linux/AppleMagicTouchstream.Windows/MotionProfiles/README.md)
for commands, captured values and hardware verification steps. Profiles are embedded
in the Windows app explicitly; they are not added to or required by the Mac app.
